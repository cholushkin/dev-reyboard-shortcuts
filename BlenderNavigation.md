# Blender Camera Navigation (Numpad)
This tool maps Unity's Scene View camera navigation to authentic Blender Numpad shortcuts for a seamless transition between the two programs. 

### Standard Orthographic Views
* **Top View:** `Numpad 7`
* **Bottom View:** `Ctrl + Numpad 7`
* **Front View:** `Numpad 1`
* **Back View:** `Ctrl + Numpad 1`
* **Right View:** `Numpad 3`
* **Left View:** `Ctrl + Numpad 3`
* **Flip View 180°:** `Numpad 9`

### Local Axis Views (Active Object)
* **Local Top View:** `Shift + Numpad 7`
* **Local Bottom View:** `Ctrl + Shift + Numpad 7`
* **Local Front View:** `Shift + Numpad 1`
* **Local Back View:** `Ctrl + Shift + Numpad 1`
* **Local Right View:** `Shift + Numpad 3`
* **Local Left View:** `Ctrl + Shift + Numpad 3`

### Projection, Focus & Isolation
* **Toggle Perspective/Orthographic:** `Numpad 5`
* **Frame Selected:** `Numpad .` (Period)
* **Toggle Local View (Isolation):** `Numpad /` (Slash)

### Active Camera Control
* **Look Through Active Camera:** `Numpad 0`
* **Align Active Camera to View:** `Ctrl + Alt + Numpad 0`
* **Set Active Object as Camera:** `Ctrl + Numpad 0`

### Panning & Orbiting
* **Orbit:** `Numpad 4`, `6`, `8`, `2` (Left, Right, Up, Down)
* **Pan:** `Ctrl + Numpad 4`, `6`, `8`, `2` (Left, Right, Up, Down)
* **Roll Camera:** `Shift + Numpad 4`, `6` (Roll Left, Roll Right)

### Zooming
* **Zoom In:** `Numpad +`
* **Zoom Out:** `Numpad -`
